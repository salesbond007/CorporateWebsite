# public/illustrations/

各サービスのイラストをここに配置すると、`/services` のカードに自動で反映されます。

## 推奨ファイル

正方形 600×600 以上の PNG（透過推奨）を配置し、`src/lib/site.ts` の対応するサービスに `image` を設定してください。

## おすすめのフリー素材サイト

「Pollock」のような手描き風キャラクターイラストを無料で入手できます。

| サイト | 特徴 |
| --- | --- |
| [Loose Drawing](https://loosedrawing.com) | 手描き風・CC0完全フリー・SVG/PNG・**Pollock系の雰囲気にもっとも近い** |
| [Linustock](https://www.linustock.com) | シンプル線画・フリー（要クレジット） |
| [Storyset](https://storyset.com) | 色変更可・フリー（要クレジット） |
| [unDraw](https://undraw.co) | カラーカスタマイズ可・フリー |
| [イラストAC](https://www.ac-illust.com/) | 大量・要無料会員登録 |

- 新規開拓支援事業: 「商談」「握手」「ビジネス会話」「営業」

## サイズ・色合わせのコツ

- 背景透過のPNGがおすすめ（カード背景の薄オレンジに馴染みます）
- イラストの主色をブランドオレンジ `#F58220` 系に揃えると統一感が出ます
- Loose Drawing の場合、SVGダウンロード後に `fill` 属性を一括置換すれば色を変えられます
