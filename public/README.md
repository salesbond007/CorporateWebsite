# public/

このフォルダに配置したファイルは、サイトのルート (`/`) から直接配信されます。

## 必要なロゴアセット

| ファイル名 | 用途 | 推奨サイズ | 形式 |
| --- | --- | --- | --- |
| `logo.png` | ヘッダー / フッターに表示される正方形ロゴ（アイコン + SalesBond テキスト） | 540×540 以上の正方形 | PNG（透過背景推奨） |
| `logo-mark.png` | （任意）アイコン部分のみのバージョン。ヘッダーをよりコンパクトにしたい場合用 | 240×240 程度の正方形 | PNG（透過背景推奨） |

**最低限必要なのは `logo.png` のみ**です。提供いただいた SalesBond ロゴ画像をそのまま `logo.png` という名前でこのフォルダ (`public/`) に保存してください。

## ファビコン（任意）

ブラウザタブのアイコンを差し替える場合は、ロゴから派生したアイコンを `src/app/icon.png`（256×256 推奨）として保存してください。Next.js が自動的に `<link rel="icon">` を出力します。
